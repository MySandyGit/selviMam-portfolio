# Dr. Selvi Shanmugi · Psychotherapist Portfolio

A quiet wellness magazine editorial portfolio designed for Dr. Selvi Shanmugi, M.Sc. Clinical Psychology. Built in vanilla HTML5, CSS3, and JavaScript with no dependencies, no framework, and no build step.

## 🌿 Deploy to Netlify (Drag & Drop)
1. Unzip `dr-selvi-shanmugi-portfolio.zip` or clone this directory.
2. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
3. Drag the folder directly into Netlify. It will deploy instantly with HTTPS!

## 🍂 Deploy to GitHub Pages
1. Push this directory to your GitHub repository.
2. In your GitHub repository, open **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/(root)`.
4. Click **Save**. Your site will be live in 1-2 minutes.

## 📝 Editing Text & Details
All site copy, credentials, doctor details, phone numbers, and timeline events are cleanly separated in:
`js/content.js`

Non-developers can change any text there without touching any layout code.

## 🎨 Design System & Visuals
- **Look**: Quiet wellness magazine: warm paper (`#EAEFF6`), darker paper (`#DDE5F0`), ink (`#1F2A44`), sea-blue (`#5F8FA3`).
- **Typography**: Bodoni Moda (variable Didone display), Inter (clean labels and body).
- **Hero Motion**: Hero title rises in behind her portrait; portrait cut-out overlaps lower part of the title; hero photo melts into paper on scroll.
- **Micro-interactions**: 1-minute guided box (4-4-4-4) & calming (4-7-8) breathing exercise; Web Audio soothing ambient soundscape; dark paper mode toggle.
- **Recorder Mode**: Append `?rec=1` to the URL for deterministic 6.5s keyframed scroll animation.
